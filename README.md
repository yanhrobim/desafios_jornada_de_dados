## 🖊️ Sobre a Jornada
A ([Jornada de Dados](https://suajornadadedados.com.br/)) é um Roadmap voltado para estudos da área de dados em programação como: *Engenharia de Dados*, *Ciência de Dados* e *Analista de Dados*. O Roadmap contém **bootcamps** e workshops, para aprendizagem de ferramentas, linguagens amplamente utilizadas na área, através de práticas, projetos, exercícios, visando o auxílio a masterizar suas habilidades dentre aquilo que você tem o interesse de aprender.

## 🤔 O Por que Deste Repositório
Com o objetivo de retomar/reforçar os estudos de programação orientada à área de dados, peguei desafios que são exercícios disponibilizados pelo Roadmap Jornada de Dados para prática de **Python** e **SQL**, visando praticar e, consequentemente, melhorar a lógica de programação dentre as linguagens. Em resumo, um repositório para prática visando melhorar habilidades.

## 🧪 Desafio Python
Antes de qualquer coisa, tive a escolha de fazer o desafio em Python puro, não a fim de **"reinventar a roda"**, e sim entender melhor a linguagem como: módulos disponibilizados pela própria linguagem, conhecer melhor o Python e principalmente melhorar a lógica de programação.

* Para a visualização da documentação do desafio contendo introdução, objetivos, regras de validação, consulte o [README](../desafios_jornada_de_dados/desafio_python/README.md), localizado em `./desafio_python/`.

* Dentro de módulos `.py` no repositório onde **possui** as soluções através de código, contém algumas observações em texto ***#***, simulando um tipo de documentação do código para auxiliar a um melhor entendimento do **raciocínio** utilizado, o por que a escolha de tais comandos ou maneira de fazer algo.
